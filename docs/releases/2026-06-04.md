# Release Notes: 2026-06-04

## `2026.6.4`

Rack's first date-versioned release.

- Adds version reporting through `rack --version` and `rack version`.
- Adds self-hosted Rack tests and release signoff.
- Adds CI, trusted PyPI release workflow, committed lockfile policy, and
  release metadata validation.
- Documents current legacy exceptions for the monolithic CLI module and Pyright
  strict-mode migration.

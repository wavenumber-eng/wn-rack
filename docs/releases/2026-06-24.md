# Release Notes: 2026-06-24

## `2026.6.24`

Rack runtime progress reporting release.

- Adds `ProgressReporter` for Python suites.
- Adds `rack run --progress` and `--no-progress`.
- Adds manifest-driven progress opt-in through `progress = true` and long
  runtime profiles.
- Tails progress JSONL from the Rack runner and prints live `RACK_PROGRESS`
  status lines to stderr.
- Adds `rack progress helper cpp --output ...` to export the canonical
  dependency-free C++ `rack_progress.hpp` helper.
- Writes progress events to `rack_results/progress/<run_id>.jsonl` and can emit
  live `RACK_PROGRESS` stderr lines for agents and terminal users.

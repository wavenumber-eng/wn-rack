# Release Notes: 2026-07-16

## `2026.7.16`

Rack native audit release.

- Adds `rack audit [stratum] [--strict] [--format text|json]`.
- Adds `rack.audit.audit_suite()` and public `rack.audit_suite`.
- Adds public `AuditReport` and `AuditFailure` result objects.
- Adds `docs/contracts/rack_audit_report.a0.schema.json` for
  `rack audit --format json`.
- Fails manifest drift for missing stratum manifests, undeclared test files,
  declared files that do not exist, duplicate subtest ids/files, duplicate
  `[strata].order` entries, missing signoff strata, and optional strict
  inventory metadata gaps.
- Keeps audit failures inside the versioned JSON contract for invalid
  `rack.toml`, including when a stratum argument is supplied.
- Adds dev-std CLI governance dogfood metadata for the public Rack CLI surface.

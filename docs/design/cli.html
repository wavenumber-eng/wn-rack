Rack CLI

list

Lists configured strata or subtests, optionally filtered by concern.

run

Runs selected strata, subtests, or individual pytest tests.

status

Displays the current aggregated suite status from previous results.

report

Regenerates the HTML report from existing JSON results.

refresh

Rebuilds Rack stratum summaries from raw pytest JSON reports.

inventory

Reports test-case inventory and orphaned case directories.

new

Scaffolds new strata and subtests.

version

Reports Rack, Python, pytest, pytest-json-report, and tomli-w versions.

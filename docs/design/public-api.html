Public API

ProgressReporter

Emits Rack runtime progress JSONL events for long-running tests.

RackOutput

Collects metrics, timings, comparisons, attachments, SVGs, tags, and status.

get_current_output

Returns the thread-local output collector for the current test.

set_current_output

Sets the thread-local output collector for the current test.

clear_current_output

Clears the thread-local output collector.
